# Projeto CETEC - Minigames

## Como executar

1. Clone o repositorio:

```bash
git clone 
```
2. Abra o arquivo `index.html`:

- No Windows, abra a pasta do projeto e clique duas vezes em `index.html`; ou
- No VS Code, clique com o botao direito em `index.html` e escolha **Open with Default Browser**.

O site sera aberto no navegador. Nao e necessario instalar dependencias ou executar um servidor.

## Arquivos principais

- `index.html`: estrutura da pagina.
- `style.css`: estilos visuais.
- `games.app.js`: mecanicas dos minigames.
